Shopping Services API

Microservicios serverless de catálogo, carrito, órdenes y pago simulado. Esta raíz no expone datos: usa los siguientes accesos para explorar la API.

Documentación Swagger UI Explora y prueba los endpoints con Try it out. Contrato OpenAPI JSON Especificación OpenAPI 3.0 completa. Sistema Health check GET /api/health Catálogo Productos GET /api/products

Endpoints disponibles

  • GET /api/products?search=&category=
  • GET /api/products/:id
  • POST /api/cart/validate
  • POST /api/orders
  • GET /api/orders/:id
  • GET /api/openapi

Pago simulado: las tarjetas terminadas en 0000 se rechazan con HTTP 402. El catálogo y las órdenes viven en memoria y se reinician en cada cold start. Consulta la documentación interactiva para ver esquemas y ejemplos.
